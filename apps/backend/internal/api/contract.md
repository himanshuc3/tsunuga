## API Contract

1. POST/PATCH `/lesson/{lessonID}/item/{itemID}` - update item's progress
2. GET `/lessson/{lessonID}/item/all` - get all items and their progress
3. GET `/lesson/next` - get next lesson
4. GET `/lesson/all` - get all lesson data
5. GET `/lesson/{lessonID}` - get a specific lesson
6. GET `/lesson/unlocked` - get all the unlocked lessons

7. GET `/settings` - get a users settings
8. PATCH `/settings` - update a users settings
